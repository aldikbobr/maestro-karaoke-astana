# Maestro — концепт сайта

Концепт-сайт караоке-клуба **Maestro** (Астана, проспект Туран, 27).

- Сайт: https://maestro-karaoke-astana.vercel.app
- Закрыт от поисковиков (`noindex, nofollow`), в подвале помечен как концепт.
- Зачем: 4,9 и 1 718 оценок в 2ГИС, но своего сайта нет. Google Карты ведут на страницу-агрегатор restoran.kz.

## Что внутри
- Прелоадер с крутящейся пластинкой, плавный скролл (Lenis), сцены GSAP ScrollTrigger, лёгкое зерно.
- Первый экран: прожекторы ходят по сцене, золотой заголовок, внизу «живой» эквалайзер, который подпрыгивает рядом с курсором.
- Залы: бархатный занавес раздвигается при прокрутке и открывает общий зал и VIP-кабинки.
- Звук: микшерный пульт, фейдеры которого поднимаются при появлении.
- Караоке-рулетка: колесо выбирает, с чего начать вечер.
- Отзывы-пластинки каруселью, часы и контакты, бронь в WhatsApp, FAQ.
